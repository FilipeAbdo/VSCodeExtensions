# Example Node.js Project

A minimal JavaScript console application. Requires Node.js and npm; no external
dependencies or installation step are needed.

## Run

From the generated project's folder:

```sh
npm start
```

Expected output:

```text
Hello from your new project!
```

## Customize

Edit [folderExample/index.js](folderExample/index.js) to start building your
application. Update the name and description in [package.json](package.json) for
your project; the template manager copies files without substituting values.
